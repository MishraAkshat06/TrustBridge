# Android Liquid Glass (Kyant0) Skill

## Architectural & Optical Invariants
1. **AGSL RuntimeShader Execution**:
   - Utilizes `android.graphics.RuntimeShader` combined with `android.graphics.RenderEffect`.
   - Requires Android 13 (API level 33) or higher.
2. **SDF (Signed Distance Field) Border Normals**:
   - Normal vectors generated by computing gradient of rounded box distance field:
     $d(\mathbf{p}, \mathbf{b}, r) = \|\max(|\mathbf{p}| - \mathbf{b} + r, 0)\| + \min(\max(p_x - b_x + r, p_y - b_y + r), 0) - r$.
   - Normal $\mathbf{N} = \text{normalize}\left(\nabla d\right)$.
3. **Snell's Law Refraction Mapping**:
   - Sample underlying view buffer with refraction offset: $\mathbf{uv}_{\text{refracted}} = \mathbf{uv} + \mathbf{N}_{xy} \cdot \eta_{\text{ratio}}$.
4. **Blinn-Phong Specular Bevel**:
   - Specular light: $I_{\text{spec}} = (\mathbf{N} \cdot \mathbf{H})^{\alpha} \cdot C_{\text{light}}$, giving crisp frosted glass edges.

## AGSL Shader Implementation

```agsl
uniform shader composableContent;
uniform float2 size;
uniform float cornerRadius;
uniform float refractionIndex; // e.g. 0.03
uniform float specularIntensity; // e.g. 0.6

float sdRoundedBox(float2 p, float2 b, float r) {
    float2 q = abs(p) - b + r;
    return min(max(q.x, q.y), 0.0) + length(max(q, 0.0)) - r;
}

half4 main(float2 fragCoord) {
    float2 center = size * 0.5;
    float2 halfSize = center;
    float2 p = fragCoord - center;
    
    float dist = sdRoundedBox(p, halfSize, cornerRadius);
    
    // Compute normal from distance gradient
    float eps = 1.0;
    float dx = sdRoundedBox(p + float2(eps, 0.0), halfSize, cornerRadius) - dist;
    float dy = sdRoundedBox(p + float2(0.0, eps), halfSize, cornerRadius) - dist;
    float3 normal = normalize(float3(dx, dy, 1.5));
    
    // Refract background
    float2 refractedUV = (fragCoord + normal.xy * refractionIndex * 100.0) / size;
    half4 bg = composableContent.eval(clamp(refractedUV * size, float2(0.0), size));
    
    // Light calculation
    float3 lightDir = normalize(float3(-0.5, -0.7, 1.0));
    float3 viewDir = float3(0.0, 0.0, 1.0);
    float3 halfDir = normalize(lightDir + viewDir);
    float spec = pow(max(dot(normal, halfDir), 0.0), 32.0) * specularIntensity;
    
    // Rim lighting
    float rim = pow(1.0 - max(dot(normal, viewDir), 0.0), 3.0) * 0.3;
    
    return half4(bg.rgb + spec + rim, bg.a);
}
```

## Jetpack Compose Modifier Integration

```kotlin
fun Modifier.liquidGlass(
    cornerRadius: Dp = 24.dp,
    refraction: Float = 0.03f,
    specular: Float = 0.5f
): Modifier = this.then(
    Modifier.graphicsLayer {
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU) {
            val shader = RuntimeShader(LIQUID_GLASS_AGSL).apply {
                setFloatUniform("size", size.width, size.height)
                setFloatUniform("cornerRadius", cornerRadius.toPx())
                setFloatUniform("refractionIndex", refraction)
                setFloatUniform("specularIntensity", specular)
            }
            renderEffect = RenderEffect.createRuntimeShaderEffect(shader, "composableContent").asComposeRenderEffect()
        }
    }
)
```
