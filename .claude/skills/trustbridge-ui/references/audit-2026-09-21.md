# UI audit — 2026-09-21

A dated snapshot of what is wrong in the TrustBridge frontend and where. **This
is a snapshot, not a standing truth.** Every time you fix something, delete its
row. If a line number here disagrees with the source, the source wins.

"Looks like it was made by an amateur or an AI — unprofessional, cheap, like a
scam site" was the owner's own description of the UI. This file is the evidence
for why, and it is all repairable.

---

## 1. `pages/Landing.jsx` — the worst, and the most visible

71 hex/rgba literals. Specific patterns:

- **Lines 25–26, 31–32, 50–51, 70, 81–82, 93–94:** theme chosen in JavaScript
  with hardcoded hex on both branches — `isDarkMode ? 'bg-[#06080D] text-white'
  : 'bg-[#FAF9F6] text-[#111827]'`. The palette is duplicated into the component,
  so it cannot stay in sync with `index.css`. Replace with tokens.
- **Line 31:** `bg-radial-[at_75%_25%] from-[#1F1708] via-[#0B0D13] to-[#06080D]`
  — a radial gradient wash. Decoration, and banned by `design.md` §1.
- **Lines 37–39:** three absolutely-positioned decorative circles behind the hero
  — `w-[600px] h-[600px] rounded-full border … animate-pulse`, a `w-[420px]`
  rotated ring, and a `w-[680px] bg-[#EAB308]/10 blur-3xl` bloom. This is the
  single strongest "template crypto landing page" signal in the repo. Delete all
  three.
- **Line 53:** a pulsing dot next to the hero badge — the fake "live" indicator.
- **Lines 60–63:** the headline colours individual words in two different greens
  (`#00D09C`, `#009379`). Named explicitly as a generated-page tell. One colour
  for the whole headline.
- **Line 58:** `text-4xl sm:text-5xl lg:text-[54px] font-extrabold` — an arbitrary
  54px that no other page uses. Pick a rung of the shared ramp.
- **Lines 81–82:** the primary CTA is a gradient-filled pill with a coloured glow
  — `bg-gradient-to-r from-[#00D09C] to-[#009379] … shadow-[0_0_20px_rgba(0,208,156,0.35)]`
  (and a gold glow in dark). Glow + gradient + pill, on the most important button
  in the product.
- **`.liquid-prism`** is applied here and nowhere else — the spinning
  holographic conic gradient described in §3.

What the hero should be instead: the real funding figure, the contract address,
the milestone schedule, and one primary action. The subject matter is already
interesting; it does not need a light show.

## 3. `index.css` — ornament inventory

374 lines, 102 hex/rgba literals. Which ornament is live, and where:

| Class | Lines | Used by | Verdict |
|---|---|---|---|
| `.card-3d` (+ `.fintech-card` alias) | 140–167 | `Explore.jsx` only | Live. Hover does `translateY(-4px) scale(1.01)` **plus a green glow** `0 0 20px rgba(0,208,156,0.1)`. The glow goes; the lift is arguable. `.fintech-card` itself is referenced nowhere. |
| `.btn-fintech-primary` | 170–194 | buttons | Live. **Gradient fill + glow + pill radius, and `color: #FFFFFF` on `#00D09C` = 2.00:1 contrast.** `design.md` §11 item 2 says the label must be `#111827`. Also hardcodes its colours instead of reading `--accent-brand`. |
| `.btn-fintech-secondary` | 196–207 | buttons | Mostly fine. Uses `transition: all` (line 201). |
| `.pulse-dot` | 209–223 | `App.jsx`, `CampaignDetails.jsx` | Infinite idle animation. Justify it or drop it. |
| `.card-tilt-3d` + `layer-*` | 235–259 | `GlassCard3D.jsx` only | 3D tilt with `translateZ` depth layers. See §4. |
| `.liquid-glass` | 262–293 | `GlassCard3D.jsx` only | `blur(24px) saturate(180%)` plus four-layer inset shadows. |
| `.glass-transparent` | 295–310 | `GlassCard3D.jsx` only | A second, redundant glass system. |
| `.spotlight-card` | 313–336 | `GlassCard3D.jsx` only | Mouse-tracking radial highlight. `GlassCard3D` sets `--mouse-x`/`--mouse-y`. |
| `.liquid-prism` | 339–366 | `Landing.jsx` only | `conic-gradient` + `mix-blend-mode: color-dodge` + `blur(36px)` + a 22-second infinite spin. The most fraud-shaped thing in the codebase. |

**The structural finding:** six of these nine ornament systems exist to serve
**one 66-line component** (`GlassCard3D.jsx`), plus one class on the landing page.
Replacing that component and deleting one line from `Landing.jsx` retires roughly
250 lines of CSS and almost the entire scam-signal surface. That is the highest
leverage change available in this repo.

**Also missing entirely:**
- Motion tokens (`--duration-*`, `--ease-*`) — `design.md` §6, its §11 item 3.
- Radius role tokens (`--radius-control/surface/overlay`) — §11 item 5. Today it
  is `1rem` on cards and `9999px` on buttons, everywhere, which is the banned
  "one radius for everything".
- `transition: all` appears at lines 176 and 201 — banned by `design.md` §10.
- Reduced-motion is guarded only at lines 368–374, for two selectors. `design.md`
  §6 calls for a global guard.

**Known contrast failures** (measured in `design.md` §3; not re-verified here):
`--color-success` and `--color-warning` fail the 3:1 non-text threshold and both
carry risk semantics; white-on-brand-green is 2.00:1.

## 4. `components/GlassCard3D.jsx`

66 lines. Reads `--mouse-x`/`--mouse-y` and applies `card-tilt-3d`,
`liquid-glass`, `spotlight-card`, `glass-transparent`, `perspective-stage` — i.e.
it is the sole consumer of the ornament layer above. Decide once whether cards
tilt; if they do not, this component and its CSS both go.

## 5. `context/AppContext.jsx` — data honesty

The chain integration is now real — contributions use actual `ethers` receipts
(`receipt.hash`, `receipt.blockNumber` at lines 341, 359, 388, 417, 446, 476,
506). What remains is the seeded and hardcoded material:

- **Lines 43–60:** `activities` initialised with two fabricated rows carrying
  real-looking transaction hashes (`0xb79ff43f…`, `0xcffdd3cc…`) and block numbers
  (`11746166`, `11746227`). The comment above them says *"Real verified
  activities"*. They are not verifiable on Sepolia. Either fetch them or label
  them unmistakably as sample data.
- **Lines 297–298:** `feeUsd = feeEth * 3200` — a hardcoded ETH price presented as
  a USD figure. On a page about money this is simply wrong whenever ETH is not
  $3200. Drop the USD figure or caption it as an estimate at a stated rate.
- **Lines 543–544:** a fallback campaign object with `mlScore: 78` and
  `riskLevel: 'LOW'`. A fabricated confident ML score is the worst kind of
  placeholder here — `memory.md` trap 4 flags the same shape of bug in
  `predict_success`'s hardcoded `0.82`. Show "unavailable".
- **Lines 363–364:** success copy ends in exclamation marks — "Confirmed in block
  ${…}! Contributed … ETH." Financial confirmations are statements, not
  celebrations.

## 6. Typography

`index.css:104` declares:

```
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Inter", sans-serif;
```

`Inter` sits **after** `Segoe UI` and is never loaded as a webfont (it is not in
`package.json`), so on Windows the app renders in Segoe UI and Inter never applies.
The intended typeface is dead code. Either load a real face or accept the system
stack deliberately — but today the page is set in whatever the OS hands over,
which is a large part of why it reads as unconsidered. Pair with `design.md` §5's
type ramp, and stop adding per-page arbitrary sizes like `text-[54px]`.
